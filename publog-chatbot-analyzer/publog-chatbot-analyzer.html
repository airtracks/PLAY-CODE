📊 퍼블로그 챗봇 품질 분석기

챗봇 어드민의 채팅 히스토리를 자동으로 분석해서 빈 응답·회피 답변·환각·메뉴 라우팅 버그·KB 갭을 한 화면에 보여주는 도구.

① 설치 — 두 가지 방법 중 택1

⚠️ 아래 파란 버튼을 그냥 클릭하면 동작 안 함! (Chrome 보안 정책)
반드시 드래그해서 즐겨찾기에 등록하거나 방법 B를 사용하세요.

방법 A — 즐겨찾기 등록 (1회만, 권장)

  1. Ctrl+Shift+B로 즐겨찾기 막대 표시
  2. 아래 파란 버튼을 마우스로 잡고 끌어서 즐겨찾기 막대로 드롭
  3. 이후 챗봇 어드민에서 그 즐겨찾기 클릭 = 분석 실행
📊 챗봇 분석 실행 (드래그용)

방법 B — 콘솔에 코드 붙여넣기 (즉시 실행, 매번 반복)

  1. 아래 "📋 코드 복사" 클릭
  2. 챗봇 어드민 접속
  3. F12 → Console 탭 → 붙여넣기 → Enter

② 사용

  1. https://chatbot.publog.co.kr/admin/ 접속 (로그인 상태)
  2. 북마크에서 "📊 챗봇 분석 실행" 클릭
  3. 새 창에 분석 리포트가 생성됨 (전체 30일 또는 날짜 선택 가능)

③ 리포트 내용

  • 📈 핵심 지표: 세션수 / Q&A / 빈응답률 / 회피율 / 정상답변률
  • 🔴 빈 응답 목록 (질문은 들어왔는데 챗봇이 답 못한 케이스)
  • 🟠 회피 답변 ("사이트에서 확인하세요" / "상담사 연결" 패턴)
  • 🟡 잘못된 답변 후보 (정책 충돌·날짜 오류 키워드)
  • 🔄 메뉴 라우팅 버그 (메뉴 클릭 → 빈/엉뚱 답변)
  • 🔁 같은 질문 반복 (사용자 답답함 신호)
  • 📚 KB 갭 후보 ("안내 문서에 없습니다", "명시되어 있지 않" 등)
  • 📥 JSON 다운로드 (Notion 보고용)
